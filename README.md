# CosmoScan — Анализатор состава косметики для Android

Мобильное приложение для проверки косметических средств (кремов, шампуней, бальзамов, масел, тоников) по камере смартфона перед покупкой.

## Основные возможности
- **Распознавание состава с этикетки (CameraX + Google ML Kit OCR):** считывает перечень ингредиентов на латинице (INCI) и русском языке.
- **Проверка эффективности (правило 1% INCI):** определяет, находятся ли полезные масла, витамины и кислоты до границы консервантов/отдушек (рабочая концентрация) или после неё (маркетинговая «пустышка»).
- **Локальная база + API-фолбэк:** встроенный справочник основных компонентов сохраняется в SQLite (Room); отсутствующие вещества автоматически подгружаются из Open Beauty Facts, Wikipedia и Europe PMC (PubMed).
- **Доказательная база и исследования:** к каждому ингредиенту привязаны заключения регуляторов (CIR, SCCS) и научные публикации, а также доступна кнопка ручного прикрепления ссылок на исследования дерматологов и организаций здравоохранения.

## Быстрая публикация и сборка APK (`v1.0.0`)
1. Распакуйте архив в любую папку на Windows.
2. Запустите **`Deploy_GitHub_v1.0.0_1Click.bat`**.
3. Скрипт загрузит все файлы в репозиторий `https://github.com/AleksSoy1/CosmoScan` и создаст тег `v1.0.0`.
4. Через 2–3 минуты в разделе **Releases** появится готовый установочный файл **`CosmoScan-v1.0.0.apk`**.
